# Приёмник: добавить чтение (doGet)

Чтобы галочки списка покупок и замеры подтягивались на другие устройства **без входа
в Google**, в скрипт-приёмник нужно добавить одну функцию.

## Что сделать

1. Открыть Apps Script проекта приёмника (тот, чей адрес зашит в Медкнижке как `RELAY`).
2. Добавить функцию `doGet` — код ниже. Если `doGet` уже есть, заменить её на эту.
3. **Развернуть заново:** Deploy → Manage deployments → карандаш → Version: New version → Deploy.
   Адрес при этом не меняется, править Медкнижку не нужно.

## Код

```javascript
function doGet(e) {
  const out = v => ContentService.createTextOutput(JSON.stringify(v))
    .setMimeType(ContentService.MimeType.JSON);

  const p = (e && e.parameter) || {};
  if (!p.sheet) return out({ ok: true, ping: "жив" });

  const files = DriveApp.getFoldersByName("База данных");
  let file = null;
  while (files.hasNext()) {
    const it = files.next().getFilesByName(p.sheet);
    if (it.hasNext()) { file = it.next(); break; }
  }
  if (!file) return out({ ok: false, error: "нет таблицы " + p.sheet });

  const sh = SpreadsheetApp.open(file).getSheets()[0];
  const all = sh.getDataRange().getValues();
  const body = all.slice(1).filter(r => String(r[0] || "").trim() !== "");
  const rows = p.last ? body.slice(-1) : body;

  return out({ ok: true, rows: rows.map(r => r.map(c =>
    (c instanceof Date) ? c.toISOString() : String(c)
  )) });
}
```

## Проверка

Открыть в браузере адрес приёмника с параметром:

```
<адрес приёмника>/exec?sheet=24_Покупки_отмечено&last=1
```

Должно вернуться `{"ok":true,"rows":[[...]]}`. После этого Медкнижка начнёт подтягивать
галочки покупок и замеры сама, при каждом открытии раздела «Питание».
